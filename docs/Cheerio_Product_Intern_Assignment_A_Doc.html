Part 1 (Continued): Solution Architecture, Guardrails & North Star

3. Description of Chosen Solution: Cheerio Copilot & Self-Healing Diagnostics

Unlike passive chatbots that send docs links, Cheerio Copilot operates as an in-workflow autonomous agent directly embedded into the user's workspace:

  • What It DOES:
    1. Proactive Workspace Telemetry: Listens to Meta Graph API responses (e.g. Error 132000, 131031) and displays a "Setup Health Scorecard" before users submit tickets.
    2. Bilingual Plain-Language Translation: Translates technical errors into conversational English & Hinglish (e.g., "Meta ne sample value na hone ki wajah se reject kiya").
    3. 1-Click AutoFix Actions: Injects sample variables, reformats text prefixes, re-tags categories, and links fuzzy AI fallback nodes with a single user click.
    4. Pre-Packaged Diagnostic Dossier: Bundles WABA ID, phone ID, Meta error codes, and previous attempts into an automated ticket when escalating to humans.
  • What It Will NOT Do (Strict Guardrails & Boundaries):
    1. No Destructive Data Mutations: Cannot delete customer contact lists, campaigns, or payment methods without 2FA confirmation.
    2. No Overriding Meta Anti-Spam Bans: Cannot magically unban numbers flagged by Meta; prepares an official Meta Appeal Packet with legal document verification instead.
    3. No Financial Discretion: Will not issue subscription refunds or alter plan prices; billing queries are escalated to human finance leads.
    4. No Unconstrained Open Chat: Rejects off-topic queries to prevent hallucination and maintain token frugality.

4. When Does a Human Still Need to Step In? (Warm Escalation Protocol)

Human agents step in only for high-friction, regulated, or emotionally sensitive scenarios:

Escalation Category Trigger Event AI Copilot Action Before Handoff Human Agent Workflow (Zero Back-and-Forth)
Meta Account Suspension WABA status: RESTRICTED / BANNED Compiles business registration docs, WABA ID & logs. Meta Partner Liaison submits priority appeal to Meta Partner Desk.
Billing & Commercial Refund requests, invoice disputes, tier upgrades Verifies subscription plan & payment gateway log. Finance Lead reviews charge history and processes adjustment.
Sentiment & Anger Spikes Sentiment score < 0.3 ("fraud", "talk to human") Freezes AI immediately; acknowledges user urgency. Senior Support Lead joins live chat within 3 minutes with full context.
Multi-Attempt Failure 2 failed auto-fixes in a single user session Packages system state and screen recording. L2 Technical Specialist diagnoses custom webhook or payload mismatch.

Impact: Because human agents receive a complete Diagnostic Dossier, Average Handling Time (AHT) drops from 18 minutes to 7 minutes (-61%).

Step-by-Step User Journey Demonstrated in Prototype:
